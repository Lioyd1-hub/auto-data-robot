# auto-data-robot 多系统数据搬运机器人

一个用 Python 实现的 RPA 全流程自动化工具：把三个业务系统（ERP / CRM / 财务）各自导出的对账数据，自动搬进汇总表并回写归档，支持无人值守、异常兜底、截图留证与错误日志。

> 目标：让「跨系统对账数据搬运」从每天 3 小时人工操作，降到 12 分钟自动完成。

---

## 解决的问题

| 痛点 | 方案 |
|------|------|
| 人工搬数单次约 3 小时，跨表漏行频发 | 编排成一条可重复、可追溯的自动化流水线 |
| 页面加载慢、容易误操作 | 界面元素定位 + 等待图像 + 超时重试 |
| 夜间批量任务无人盯守 | 定时调度 + 时间区间判断 + 失败重试 + 邮件告警 |
| 失败后难以追溯 | 失败即截图，写入错误日志表，按天归档 |

## 核心能力

- **流程编排**：循环 / 条件 / 多分支路由 / 异常兜底 / 维护时段等待
- **数据搬运**：Excel 驱动循环读取待处理单号，逐行处理，结果回写原表并标记状态
- **界面定位**：元素定位 + 等待图像 + 超时重试
- **异常兜底**：失败即截图，写入错误日志表，不中断整体流程
- **无人值守**：定时调度 + 时间区间条件判断 + 失败重试 + 邮件告警

## 量化结果

- 日均处理 **200+** 条记录
- 单次耗时由 **180 分钟降至 12 分钟**
- 连续运行 **21 天**，抽检 200 条准确率 **99.5%**
- 定时任务连续 **30 天零漏跑**，累计处理 6000+ 条，4 次异常全部自动恢复并留证

## 快速开始

```bash
# 安装依赖
pip install pandas pyyaml openpyxl

# 运行一次数据搬运（示例数据）
python robot_core.py --once

# 进入无人值守调度模式
python robot_core.py --schedule
```
